## Final scaffold prompt schema (for reference)

The `_build_scaffold_sampling_prompt` JSON schema now requires:
- `narrative` — senior-QA framing
- `task_refinements` — sharpened assertions on host-supplied tasks
- `boundary_scaffolds` — enforcement-layer scaffolds for "blocked at X time" ACs
- `uncovered_branches` — proposed scaffolds for branches the host under-covered
- `cross_cutting_assertions` — properties that apply to every result entry
- `top_risks` — change-specific risks linked to scaffolds
- `principle_citations` — ISTQB Foundation principles per task
- `named_techniques` — ISTQB techniques per task
- `specialty_needs` — `[{specialty, tool}]` or `[]` if in-process
- `assumptions` — HARD REQUIREMENT, every behavioural inference labelled

This schema is the "senior-QA shape" the rubric asks for. Other tools have analogous schemas.
