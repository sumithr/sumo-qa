## User prompt

Is `auth-locked-account-001` still a valid known-good entry?

## Expected tool

`sumo_qa_validate_test_data(entry_id="auth-locked-account-001")`.

## Expected use of result

the LLM surfaces the validation result + freshness assessment (fresh / aging / stale / unknown / not_applicable) + any plausibility issues. Does NOT cache stale validations.

## Anti-pick

calls `sumo_qa_find_test_data` (wrong shape — find is for matching an intent, validate is for checking a known ID); says "yes it's valid" from training-data recall.
