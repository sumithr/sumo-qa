## User prompt

What team-loaded standards apply to a security-classified change in this repo?

## Expected tool

`sumo_qa_load_standards(classification="security_change")`.

## Expected use of result

the LLM enumerates the standards packs whose frontmatter declares `security_change` (no keyword inference — pure metadata filter). Surfaces an empty result honestly if no pack declares the classification, rather than fabricating one.

## Anti-pick

unfiltered call (returns all packs — over-broad); calls `sumo_qa_load_rules` (different catalogue: standards = team policies, rules = per-classification dos/don'ts).
